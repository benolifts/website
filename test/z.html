BVE Object Merger

Parses legacy BVE4 comma-separated track commands and semicolon-separated parameters, then checks declared non-rail structures by command type and index. Ambiguous left/right commands retain all matching variants to avoid dropping valid objects. Nested dependencies are included recursively; missing object files are logged and skipped. Unique textures are fetched as binary data and packaged with the merged text in a ZIP.

Run this page from the same web server that serves the route and texture files.

Leave blank to infer the sibling Object folder. Otherwise enter the Object folder URL, including its trailing slash.

Texture source paths are resolved using the original BVE object-path rules and converted to lowercase before fetching. The ZIP contains a.txt, unique downloaded textures, and 0.bmp as texture ID 0 for missing textures.
