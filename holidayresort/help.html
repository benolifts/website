The aim of the game is to build the bigest holiday resort.
Build 3 of the same item next to each other to upgrade them, but think adhead of where this upgrade item will appear so you can get 3 of those in a row for an even better upgrade.
e.g. build 3 tents next to each other gives you a bigger tent, build 3 big tents next to each other to get a caravan, build 3 caravans next to each other to get a mobile home, and so on...
Also there will sometimes be pests in the holiday resort, these don't do any harm but they get in the way. Trap the pests to kill them and they will turn into a stone (if you kill more than one pest at a time the stone will be placed at random). If you get 3 stones next to each other you will get a stonehenge, 3 stonehenges makee a castle, and so on...
There is also the star, the star will turn into ANY item, so if you only have 2 items the same, use the star to act as the 3rd item so you can upgrade.
The red X lets you delete something

Scoring
Your score is how much value your resort is worth. each tent is worth 1 point, big tent 5 points, caravan 25 points, mobile home 125 points, bungalow 625 points, and so on (multiplying by 5 of the points of the last value item. 1,5,25,125,625,3125,15625... So that the new upgraded item is worth 5 time the value to one of the items used to upgrade it)
stones are worth 6, stonehenge 30, castle 150, and so on multyplying by 5.
ore is worth 3, bronze statue 15, silver statue 75, and so on multyplying by 5.
